# Portfolio Website

A portfolio website generator written with the Python standard library only. It is the Day 83 assignment of the Udemy course "100 Days of Code: The Complete Python Pro Bootcamp": show your skills and the projects you have built, on a home page and an about page.

This wiki explains the project one step at a time. Every step has a page that says what the step builds and what we gained from it, with a picture taken from this project's own output.

Start with [Getting started](Getting-Started) to run the site on your own computer, read the [Lecture summary](Lecture-Summary) for the idea behind the assignment, then follow the steps.

- [Step 1: Project data](Step-1-Project-Data): projects live in a JSON file
- [Step 2: Home page](Step-2-Home-Page): the `home` use case and its page
- [Step 3: About page](Step-3-About-Page): the `about` use case and its page
- [Step 4: Style](Step-4-Style): a responsive stylesheet
- [Step 5: Preview](Step-5-Preview): the `build` and `serve` commands
- [Step 6: Tests](Step-6-Tests): pytest, layer checks and linters
- [Step 7: Flip cards and profile](Step-7-Flip-Cards-and-Profile): flip cards, tags, skills, the LinkedIn link and the profile photo

The source code and the project documents are in the [repository](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/083-assignment-website-portfolio).
