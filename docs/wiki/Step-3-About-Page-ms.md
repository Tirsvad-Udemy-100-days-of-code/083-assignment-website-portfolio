# Langkah 3: Halaman tentang

## Apa yang dibina dalam langkah ini

Kes guna `about` membaca profil pemilik (nama, tajuk kecil, ringkasan, kemahiran dan pautan) dan memulangkan `AboutPage`. Halaman itu menunjukkan siapa pemiliknya, kemahiran sebagai senarai dan pautan seperti GitHub dan LinkedIn. Pautan hanya diterima jika bermula dengan `http://` atau `https://`.

![Halaman tentang tanpa helaian gaya](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/083-assignment-website-portfolio/raw/branch/main/docs/images/step-03-about-page.png)

## Apa yang kita pelajari

- Halaman kedua menggunakan semula susun atur dan navigasi yang sama, jadi perubahan pada pengepala dibuat sekali sahaja.
- Pautan daripada fail data juga input pengguna: skema seperti `javascript:` ditolak.
- Corak yang sama (entiti, port repositori, kes guna, templat) berulang, jadi halaman baharu cepat ditambah.
