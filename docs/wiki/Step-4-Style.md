# Step 4: Style

## What this step builds

One stylesheet, `style.css`, gives the site its look. The projects sit in a grid that fits as many columns as the window allows and folds to one column on a phone. Colours follow the visitor's light or dark setting.

![The styled home page](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/083-assignment-website-portfolio/raw/branch/main/docs/images/step-04-styled-home-page.png)

![The same page on a narrow screen](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/083-assignment-website-portfolio/raw/branch/main/docs/images/step-04-narrow-screen.png)

## What we gained

- CSS grid with `auto-fill` makes a responsive layout without a framework and without a media query for every size.
- `prefers-color-scheme` lets the page follow the visitor's choice.
- The stylesheet is a static file next to the Python code; the build copies it into the site.

Resize the browser window while `serve` is running and watch the cards fold.
